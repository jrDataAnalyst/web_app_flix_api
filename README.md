# web_app_flix_api

🚀 Front-end Streamlit para API Django REST Framework
Aplicação front-end em Streamlit que consome uma API externa feita com Django e Django REST Framework.

🔐 Autenticação
Login via API com geração de token JWT para acesso seguro.

🔑 Permissões
Controle de acesso baseado nas permissões do usuário, definindo quais dados podem ser visualizados.

▶️ Como usar
git clone <URL-do-repositório>
cd <nome-da-pasta>
pip install -r requirements.txt
streamlit run app.py
